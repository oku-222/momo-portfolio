# MOMO PORTFOLIO

React + Viteで構築したMOMO PORTFOLIOです。

## 開発コマンド

```bash
npm install
npm run dev
npm run build
```

## 編集場所

- 作品情報：`src/data/works.js`
- ページ全体の構成：`src/App.jsx`
- 各セクション：`src/components/`
- 色・フォント・余白：`src/styles/variables.css`
- レイアウト：`src/styles/global.css` と `src/styles/responsive.css`
- 作品画像：`public/images/`

## 仮項目

- Contactのメールアドレス：`hello@example.com`
- ORB STATIONのView Projectリンク：`#`
- About本文
- プロフィール画像
